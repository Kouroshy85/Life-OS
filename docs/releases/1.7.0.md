Life OS 1.7.0 adds a local Finance module: accounts, income, expenses, atomic transfers, categories, monthly budgets, savings allocations, reports and CSV export.

- Only US dollars and Iranian rials can be selected. New records default to rials.
- A shared rial/toman switch changes display and entry units exactly; stored IRR amounts remain integer rials. One toman is ten rials, including fractional toman display for individual rials.
- Finance numbers inherit the app font, including Persian typography.
- Finance extends the existing assistant with bounded summaries and validated proposals requiring approval. Finance remains usable without AI.
- Migration v6 preserves existing planning data. Full database backups include Finance.
- Browser storage failures are reported and can be retried without replaying transactions.

Validation: 327 automated tests passed and the production frontend build passed. Browser checks covered transaction creation/edit/deletion, transfers, account archiving, budgets, savings, reload persistence, reports, mobile layout and Persian UI. Actual local-model inference was not exercised.

Packages: Windows NSIS installer and web ZIP. Android and iOS packages are not included in this release workflow. Existing mobile source support is retained.

Make a full database backup from Settings before upgrading. The Windows installer is not code signed.
