Life OS 1.9.0 adds the Lavender theme and a mobile quick-add menu.

- Lavender brings lighter card surfaces, violet navigation highlights, and updated buttons and menus. It's the default for new installations and available in Settings under Theme.
- Tap **+** in the mobile bottom bar to add a goal, transaction, plan, or income. If you need to create a Finance account first, Life OS opens the selected form after setup.
- Quick add is available in English and Persian and follows the selected language's reading direction.

Download the Windows installer or web ZIP below, or open the [live web app](https://kouroshy85.github.io/Life-OS/).
